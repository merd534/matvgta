# Prompts

This file contains prompt templates and examples.

## General Prompts

### Code Review
Review the following code for:
- Correctness
- Performance
- Security
- Readability
- Best practices

### Bug Fix
Analyze the error and provide:
1. Root cause analysis
2. Step-by-step fix
3. Testing recommendations

### Feature Implementation
Implement the requested feature with:
- Clean, maintainable code
- Proper error handling
- Documentation where necessary
- Unit tests if applicable

## Specialized Prompts

### Frontend Development
- Create responsive, accessible UI components
- Implement modern CSS techniques
- Optimize for performance and SEO

### Godot Development
- Write efficient GDScript or C# code
- Implement game mechanics and physics
- Optimize rendering and performance

### DevOps
- Set up CI/CD pipelines
- Configure deployment strategies
- Implement monitoring and logging
